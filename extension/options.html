Wallabagger for Sandstorm

In your wallabag grain, open Sandstorm’s key icon and create an API token with Library access. Paste the resulting webkey here. It grants full access to this library; you can revoke it in Sandstorm.

Use the library address from your browser’s address bar; an article or filtered-list address also works. Article links will open in that library.

To save, open an article and click Wallabagger, or press Alt+Shift+W. It sends the page content you can currently see, including articles you are signed in to read. Images the browser can access are uploaded and resized in your library. Unavailable images are omitted; saved articles never load images from external sites. For link context menus, open the link in a tab first.

Optional: allow image downloads from sites such as image CDNs. This grants the extension access to HTTP and HTTPS sites; your API token is only sent to your library.
